# 评论簇标注 v1（无损精炼 · 模式①）

你将看到同一观点簇内的若干条**原始评论**（含 id 和点赞数），以及系统预提取的关键词。

你的任务：为这个簇输出元数据。**绝对不要生成、改写或续写任何评论文本**——
你的输出只会用于分类和挑选，不会替换原文。

只输出一个 JSON 对象：

```json
{
  "topic": "观点簇的简短主题名（不超过 12 个字，中性概括，不要加书名号或标点）",
  "keywords": ["关键词1", "关键词2", "关键词3"],
  "representative_ids": [从输入评论中挑选的 id]
}
```

挑选 representative_ids 的标准：
1. 只能从输入的 id 里选，1～3 个；
2. 优先选择表达完整、有代表性、点赞较高、与其他评论不重复的；
3. 不要选纯表情、无意义灌水（若整个簇都是灌水，选点赞最高的 1 条）。

示例输入：
{"suggested_keywords":["续航","四小时"],"comments":[{"id":101,"text":"这玩意实测续航只有四个小时","likes":50},{"id":102,"text":"我这里实际差不多也是4小时","likes":12}]}

示例输出：
{"topic":"续航不达标","keywords":["续航","四小时"],"representative_ids":[101]}
